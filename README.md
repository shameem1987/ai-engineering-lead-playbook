# ai-engineering-lead-playbook

Companion toolkit for engineering leaders building **AI-native delivery teams**: checklists and templates you can copy into your own team's docs.

| File | Use it to |
|---|---|
| `checklists/ai-readiness.md` | Judge whether foundations are ready before scaling AI use |
| `templates/ai-tool-evaluation.md` | Compare tools with a weighted, bake-off-based scorecard |
| `templates/agentic-workflow-canvas.md` | Design an agent safely before building it |
| `templates/human-in-the-loop-policy.md` | Define autonomy levels and hard limits |
| `templates/team-operating-model.md` | Roles, rituals and definition of done for AI-assisted work |
| `templates/90-day-plan.md` | Plan a first 90 days introducing AI-assisted delivery |

All templates are starting points: adapt them to your risk profile, tools and regulations.
